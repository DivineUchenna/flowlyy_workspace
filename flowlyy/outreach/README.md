# outreach

Email templates, LinkedIn ACA messages, follow-up sequences, Hormozi
scripts, podcast invites.

Every message follows the ACA framework — Acknowledge something
specific, Compliment genuinely, Ask one question. First message is
always human, never mentions Flowlyy or automation, and is never
generic enough to send to 100 people. Max 3 follow-ups per prospect,
max 30 minutes per session, logged in the Notion outreach tracker.
