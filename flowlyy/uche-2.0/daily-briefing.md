# Daily Briefing — Template

Generated each morning from current vault + Notion state. Keep it short —
this is a starting point for the day, not a report.

```
FLOWLYY — <date>

INBOX (clear within 24h)
- <items currently sitting in _inbox/, with age>

CLIENTS (same-day replies)
- <any client awaiting a reply — flag as overdue if from yesterday or earlier>
- <status changes: setup → live → at-risk → churned>

PROSPECTS / OUTREACH (30 min cap)
- <follow-ups due today from Notion tracker, max 3 per prospect>
- <new prospects researched but not yet contacted>

UPWORK (20 min cap)
- <open threads / proposals awaiting reply>

CONTENT (if today is a posting day)
- <LinkedIn: Tue/Wed/Thu 11am or 4pm GMT — is today's post drafted?>
- <TikTok: Mon/Wed/Fri — is today's script drafted?>

STUDY BLOCK (9am–12pm, protected)
- <where the current course/session left off — see study/>

NORTH STAR CHECK
- <anything today that moves "zero operatives turned away" or "first paying client"? name it>
```

## How to generate this

Pull from: `_inbox/` (file listing + age), `clients/*/README or status`,
Notion outreach tracker (follow-ups due), `prospects/` (recently added,
uncontacted), `content/` (does today have a drafted post per the posting
rhythm), `study/` (most recent session file).

See [[routing-map]] for where each item type lives and
[[system-prompt]] for tone and priority order when the briefing runs long.
